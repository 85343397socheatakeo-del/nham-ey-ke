# Nham Ey Ke? (ញ៉ាំអីគេ?) - Easy Khmer Food Recipes

## 🍲 What It Does
- **Budget-Friendly Khmer Meals**: Curated recipes under $2 that require only 10–15 minutes of preparation.
- **Dorm One-Pot / Rice Cooker Cooking**: Recipes optimized for a single burner or standard electric rice cooker with minimum cleanup.
- **Bilingual Interface**: Seamless one-tap toggle between Khmer (🇰🇭) and English (🇬🇧).
- **Food Research Engine**: Instant search by ingredient, dish name, or budget.
- **Interactive Market Checklist**: Tap to check off ingredients while walking through local markets (Phsar).
- **Student Cooking Tips Inbox**: Advice from senior university students and nutritionists.
- **Interactive Editing**: Add and customize recipes, icons, photos, and YouTube cooking video embeds directly from the browser.

## 🚀 How to Run Locally
1. Clone or download this repository.
2. Open the project folder and run:
   ```bash
   node server.js
   ```
3. Open your browser to:
   ```
   http://localhost:3000
   ```
